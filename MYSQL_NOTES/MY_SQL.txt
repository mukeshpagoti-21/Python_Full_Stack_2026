MYSQL[20 DAYS]

what is data ?
--------------------
raw facts or figure without context
example :101,malli,50000,hyd

what is field ?
--------------------------
smallest unit of data in data base (column/attributes)
ex : ename,esalary,eaddress

what is record ?
----------------------------
collection of related fields (rows / tuple)
ex : (101,"sunny",5000)

what is database ?
-------------------------------
organised collection of related records stored together
ex : an employee database contains all employee record

client-server-arch ?
--------------------------------
client   :  the role of the client in client - server arch is to send request to the server and to get
            response from the server

server   : server is a software the role of the server in client - server arch is to take request from the clients.
           if the request is valid request it will generates some response and we can handover that response to client.
           if the client request is not valid request it will raise some error status codes.

protocol : it has a set of rules and regulations . in the role of the protocol in client-server arch is to send request from client to server

====================

SQL(STRUCTURED QUERY LANGUAGE)
===========================================================
--> STRUCTURED QUERY LANGUAGE (SQL) IS A STANDARD PROGRAMMING LANGUAGE SPECIALLY DESIGNED FOR MANAGING AND MANIPULATING RELATIONAL DATA BASE . IT PROVIDES A DECLARATIVE SYNTAX
    THAT ALLOWS USER TO DEFINED WHAT DATA THEY WANT RETRIVE , INSERT ,UPDATE OR DELETE WITHOUT SPECIFYING EXACTLY HOW DATABASE SHOULD EXCUTE THESSE OPERATIONS.
SQL COMMANDS
=====================
DDL : DATA DEFINITION LANGUAGE
------------------------------
DEFINES AND MODIFIES THE STRUCTURE OF DATABASE OBJECTS(TABLES , SCHEMES ,INDEX)

DCL : DATA CONTROL LANGUAGE
---------------------------
MANAGES PERMISSION AND ACCESS CONTROL ON DATA BASE

----------------------------------------------------------------------------------------------05/09
1.DROP
----------
--> REMOVES THE TABLE OR OBJECT
-->TABLE STRUCTURE + DATA
-->PERFORMANCE IS SLOW (DUE TO FULL REMOVAL)

2.DELETE
--------------
-->REMOVES SPECIFIC ROWS FROM A TABLE
-->SPECIFIC ROWS (BASED ON CONDITIONS)
-->TABLE STRUCTURE INTACT
-->PERFORMANCE IS SLOWER (ROW-BY-ROW)

3.TRUNCATE
------------------
-->REMOVES ALL ROWS ,KEEP STRUCTURE
-->ALL ROWS
-->TABLE STRUCTURE INTACT
-->PERFORMANCE IS FAST(BULK DELETION)

REFERENTIAL ACTIONS
============================================
REFERENTIAL ACTIONS DEFINE WHAT HAPPENS TO CHILD TABLE DATA WHEN PARENT TABLE DATA IS UPDATED OR DELETED

ON DELETE CASCADE ,ON UPDATE CASCADE

ON DELETE SET NULL,ON UPDATE SET NULL
